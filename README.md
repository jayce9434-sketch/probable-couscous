# BUGBREAK: Colony Siege — Update 2

A zero-dependency HTML5 canvas action/defense game built for GitHub Pages, desktop, iPad and mobile browsers.

## Update 2 changes
- Rebalanced difficulty around fun instead of punishment.
- Nest base HP increased to 760 and permanent nest upgrades are stronger.
- One-time 18 gem starter grant for new/fresh saves.
- Guaranteed early-wave gems, better regular gem drops, and guaranteed boss gem rewards.
- Permanent upgrade prices now start at 4–7 gems with gentler cost scaling.
- 10 permanent upgrades: HP, damage, speed, nest HP, nest regen, pickup radius, gem luck, dash cooldown, repair strength and critical chance.
- 12 in-run mutations.
- Two new playable insects: Ladybug (nest guardian) and Mosquito (lifesteal attacker).
- Emergency nest repair: press R or use the mobile REPAIR button; costs 12 crumbs.
- Player and nest partially heal after every cleared wave.
- Full 50-wave campaign with 10 boss rounds and a Wave 50 victory screen.
- Multiple boss species and procedural boss battle music generated with Web Audio.
- More detailed backyard art: pond, fence, soil path, flowers, grass, stones, log, mushrooms, fireflies and improved insect rendering.
- New enemy variety including roaches and wasps.
- Local save data through localStorage.

## Controls
- Move: WASD / arrow keys / touch stick
- Bite: Space / J / BITE button
- Dash: Shift / K / DASH button
- Repair nest: R / REPAIR button
- Pause: Escape / pause button

## GitHub Pages
Upload every file in this ZIP directly to the root of a repository. Then enable GitHub Pages from the repository's main branch/root.

No build step, package manager, external library, CDN, or external audio file is required.
